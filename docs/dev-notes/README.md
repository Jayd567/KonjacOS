# Development notes

Engineering notes kept while building KonjacOS. These are working
records, not user documentation.

- [history.md](history.md): the full step-by-step build log.
- [toolchain.md](toolchain.md): how the kernel builds on stable Rust, and
  the pitfalls that come with it.
- `java-*.md`, `jvm-*.md`: investigations into getting OpenJDK running.
- The other `.md` files cover individual kernel features, each with a
  matching `-validation.json` test record.
